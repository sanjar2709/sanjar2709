Most of my work code is private, so the repos here are side projects I build to try ideas
and keep my skills fresh:

- [shop-api](https://github.com/sanjar2709/shop-api): e-commerce backend in Django REST Framework.
  Cart, orders, Celery jobs, and checkout that never sells the same last item twice.
- [booking-service](https://github.com/sanjar2709/booking-service): appointment booking API in FastAPI.
  Free slots from weekly schedules, and PostgreSQL itself refuses overlapping bookings.
- [taskboard](https://github.com/sanjar2709/taskboard): kanban board in Nuxt 4 and FastAPI.
  Drag and drop, and everyone on the board sees changes live, even with several backend workers.
- [booking-bot](https://github.com/sanjar2709/booking-bot): Telegram bot for booking appointments, aiogram 3.
  Free times, reminders, an admin panel inside the bot, and three languages.
- [docs-assistant](https://github.com/sanjar2709/docs-assistant): ask questions about your PDFs and Word files.
  pgvector search with embeddings that understand Uzbek, and Claude answers with links to the exact page.
- [infra](https://github.com/sanjar2709/infra): how all of the above runs on one VPS. Ansible hardens the server,
  Traefik serves HTTPS, GitHub Actions deploys, Grafana and Telegram alerts watch it, and backups run every night.
